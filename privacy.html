Personal Workspace CLI

Privacy policy

Effective October 29, 2026. Operated by silvermanseoul for their personal use.

Google data access and use

The operator authorizes access to account identity, Gmail messages and drafts, Drive files, Google Docs, Sheets, Slides and Calendar. Data is accessed to carry out the operator's requested reads, drafts, document edits, file operations and calendar operations. OAuth permissions may also allow sending mail and deleting or sharing supported resources; actual operations remain subject to the operator's instructions and local controls.

Storage and processing

The gog CLI runs on the operator's computer and communicates with Google APIs. OAuth secrets and refresh tokens are stored in macOS Keychain, alongside local account configuration. Retrieved content may be stored in local outputs or assistant conversation records as needed for the requested workflow.

When used with coding assistants, selected Google data and tool results may be sent to the assistant provider to process the operator's request. Handling and retention by those services depend on the selected product, account settings and applicable provider policies. This workflow does not promise that all retrieved content remains exclusively on the Mac.

Sharing and limited use

The operator does not sell Google user data or use it for advertising. Google data is used for the requested personal workflow and shared with service providers only as needed to perform it. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

Access continues until the operator removes local credentials, revokes Google access or Google invalidates the authorization. Access can be revoked in Google Account connections. Revocation stops future API access; local exports and assistant records must be removed separately using the relevant file and service controls.

This information website

This static website has no application analytics, advertising scripts or Google sign-in form. GitHub Pages hosts it and may record visitor information such as IP addresses for security under the GitHub Privacy Statement.

Contact

Questions can be raised through the project's issue tracker. Do not include private account data or credentials in a public issue.
