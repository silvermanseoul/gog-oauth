Personal Workspace CLI

A private, local Google Workspace workflow operated by silvermanseoul, using the open-source gog CLI with coding assistants.

Purpose

The workflow helps its operator read Gmail and manage drafts, work with Drive files, edit Docs, Sheets and Slides, and manage Calendar entries in accounts they authorize. It is intended for the operator's own accounts, not public sign-ups.

Authorization and control

Google authorization is completed directly with Google. Credentials are stored on the operator's Mac in gog's shared local store, with OAuth secrets and refresh tokens in macOS Keychain. Gmail sending is blocked by default in the local CLI and requires an explicit operator request to permit it.

This website only provides application information. It does not sign users in or receive Google account data.
